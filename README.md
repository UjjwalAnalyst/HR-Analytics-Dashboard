# HR-Analytics-Dashboard
Power BI dashboard analyzing HR data to track attrition, workforce distribution, employee performance, and demographic trends.
This project features an interactive HR Analytics Dashboard built in Power BI to help organizations monitor employee performance, attrition, demographics, and engagement trends. The dashboard transforms raw HR data into meaningful insights that support data-driven decision-making in workforce planning, retention strategies, and productivity improvement. It includes dynamic visuals, filters, and KPIs to help HR teams understand employee behavior and organizational patterns.
